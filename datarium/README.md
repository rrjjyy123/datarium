# 데이터리움 · 학습의 기록

AI 학습데이터와 데이터 편향을 주제로 한 three.js 1인칭 탐험 게임 (초등 6학년 실과 AI 수업용).

- **프롤로그 · 폐기 데이터 보관소**: 잘못된 라벨 / 치우친 데이터 / 빠진 데이터 찾기, 정리 로봇 SORT-9 재학습
- **STAGE 1 · 치우친 과수원**: 샘플 수집 → 라벨링 → 학습(최근접 이웃) → 테스트 → 윤리 질문
- STAGE 2 · 가짜 라벨 시장 (준비 중)

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다. (three.js r128을 cdnjs에서 불러오므로 인터넷 연결 필요)

## 수정
`src/` 파일을 고친 뒤 `python build.py`로 `index.html`을 다시 만듭니다.

| 파일 | 내용 |
|---|---|
| `src/page.html` | 화면 구조와 스타일 |
| `src/engine.js` | 렌더러, 조작(키보드·마우스·터치), 충돌, 대화창, 사운드 |
| `src/worlds.js` | 3D 모델(비트·SORT-9·하비·과일)과 장면(보관소·과수원), 분류 모델 |
| `src/story.js` | 인트로, 프롤로그, 스테이지 1 진행 |

## 조작
PC: WASD 이동 · Shift 달리기 · 마우스 시점(화면 클릭) · E/클릭 스캔 · Q 데이터셋 · Esc 메뉴  
태블릿: 왼쪽 스틱 이동 · 화면 끌어 시점 · 스캔 버튼

게임 속 도시·인물은 모두 지어낸 이야기입니다. 입력한 이름은 기기 안에서만 쓰이며 전송되지 않습니다.
